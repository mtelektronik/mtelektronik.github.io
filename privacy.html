Prywatność strony

Dokument w trakcie uzupełniania. Podane informacje nie stanowią jeszcze kompletnej informacji prawnej.

Ta statyczna strona nie zawiera formularzy, narzędzi analitycznych ani reklam w dostarczonym kodzie. Hosting zapewnia GitHub Pages; dostawca hostingu może przetwarzać techniczne dane żądań, np. adres IP. Przed publikacją uzupełnij informacje o administratorze danych, podstawach prawnych, okresach przechowywania, odbiorcach danych i prawach osób zgodnie z rzeczywistą konfiguracją.

Administrator danych: Marcin Tchorz / MTElektronik, marcintelektro@gmail.com

Hosting: GitHub Pages (GitHub, Inc.). Sprawdź aktualne informacje dostawcy dotyczące przetwarzania danych.

Zapamiętanie języka

Strona zapisuje wybór języka w pamięci localStorage przeglądarki pod kluczem mt-language. Ten zapis nie służy śledzeniu użytkowników. Możesz go usunąć, czyszcząc dane tej witryny w przeglądarce.
